# WinManager

Многофункциональный веб-менеджер серверов с системой гостевых ключей, файловым менеджером, терминалом и мониторингом системы.

## Возможности

### Основной функционал
- Веб-интерфейс на базе Flask с темной темой
- Защищенная аутентификация с двухфакторной проверкой
- Система гостевых ключей с гибкой настройкой прав доступа
- Файловый менеджер с поддержкой операций CRUD, архивов, поиска
- Встроенный редактор кода на базе Monaco Editor
- Терминал для выполнения команд на сервере
- Дашборд с графиками системных метрик
- Мониторинг сетевых подключений
- Просмотр и очистка логов

### Безопасность
- Двухфакторная аутентификация (пароль + секретный вопрос)
- Гостевые ключи с ограничением по IP, User-Agent, времени действия
- Детальная настройка прав: просмотр, редактирование, удаление, загрузка, скачивание
- Ограничение доступа к конкретным папкам, файлам, логам, серверам
- Защита от брутфорса с автоматической блокировкой IP
- Блокировка IP-адресов и User-Agent через админ-панель
- Поддержка файла аутентификации (satch.saa) для доступа к админке
- Шифрование файла аутентификации (Fernet + PBKDF2)

### Админ-панель
- Генерация гостевых ключей с настраиваемыми правами
- Управление заблокированными IP и User-Agent
- Мониторинг активных пользователей
- История действий пользователей
- Время жизни ключей: минуты, часы, дни, навсегда
- Проверка уникальности имен ключей

### Системные метрики
- CPU, RAM, Swap, Disk I/O, Network
- Графики в реальном времени (Chart.js)
- Сетевые подключения к портам сервера
- Все активные сетевые соединения

### Файловый менеджер
- Создание, удаление, переименование, перемещение файлов и папок
- Редактирование файлов через Monaco Editor с подсветкой синтаксиса
- Загрузка и скачивание файлов
- Поиск по имени и содержимому файлов
- Поиск и замена текста в нескольких файлах
- Создание архивов (ZIP, TAR.GZ)
- Распаковка архивов (ZIP, TAR, TAR.GZ, 7Z, RAR)
- Контекстное меню с быстрыми действиями

### Управление серверами
- Запуск и остановка сторонних серверов из веб-интерфейса
- Настройка до 6 серверов через конфигурационный файл
- Раздельные логи для каждого сервера
- Терминал с выполнением команд в контексте выбранной папки

### Страницы ошибок
- 403 с шрифтом MrRobot
- 404 с шрифтом MrRobot
- 429 с видео ddos.mp4

## Установка

### Требования
- Python 3.8 или новее
- Windows (основная платформа) или Linux
- OpenSSL (для HTTPS)
